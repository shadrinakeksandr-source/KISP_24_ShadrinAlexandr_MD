Создание проекта

Узнайте, как создать новый проект на Expo.

Expo — это фреймворк для React Native, упрощающий разработку приложений для Android и iOS. Наш фреймворк предоставляет маршрутизацию на основе файлов, стандартную библиотеку нативных модулей и многое другое. Expo — это проект с открытым исходным кодом и активным сообществом на GitHub и Discord.

Мы также разрабатываем Expo Application Services (EAS) — набор сервисов, дополняющих фреймворк Expo на каждом этапе процесса разработки.

    Только начинаете программировать? Вы можете создать свое первое приложение на Expo, используя AI-агента для написания кода, вместо того чтобы писать его вручную. Ознакомьтесь с руководством «Создание с помощью ИИ» (Build with AI). В нем описан процесс настройки с нуля.

Системные требования

    Node.js (LTS).
    Поддерживаются macOS, Windows (PowerShell и WSL 2) и Linux.

Начало работы со стандартным проектом

Мы рекомендуем начать со стандартного проекта, создаваемого с помощью `create-expo-app`. Этот проект содержит примеры кода, которые помогут вам быстрее освоиться.

Чтобы создать новый проект, выполните следующую команду:
Терминал
npm
yarn
pnpm
bun

Копировать
npx create-expo-app@latest

    Вы можете выбрать другой шаблон, добавив опцию `--template`.

Начало работы с примером

Вместо стандартного проекта можно начать с одного из примеров Expo. Это небольшие приложения, каждое из которых демонстрирует определенную функцию или интеграцию, например Expo Router, Expo Widgets или экран камеры.

Чтобы просмотреть полный список и выбрать пример в интерактивном режиме, запустите `create-expo-app` с опцией `--example` без указания имени:
Терминал
npm
yarn
pnpm
bun

Копировать
npx create-expo-app@latest --example

Чтобы создать конкретный пример, укажите его имя:
Терминал
npm
yarn
pnpm
bun

Копировать
npx create-expo-app@latest --example with-widgets

    Остальные руководства в этом разделе («Начало работы») ориентированы на стандартный проект. Структура приложения-примера может отличаться, но используемые концепции остаются прежними.

Настройка AI-агента

Новый проект включает файлы контекста, которые считывают AI-агенты: `AGENTS.md`, `CLAUDE.md` и `.claude/settings.json`. Для Claude Code и Codex также существуют официальные плагины Expo. С помощью одной команды можно установить Expo Skills и зарегистрировать сервер Expo Model Context Protocol (MCP):

Claude Code

Codex
Терминал

Копировать
claude plugin install expo@claude-plugins-official

Затем выполните команду `/mcp` в сеансе Claude Code, чтобы войти в свою учетную запись Expo.

Плагин также устанавливает навык, который помогает агенту ориентироваться в структуре файлов нового проекта Expo:
expo-project-structure

Структура папок нового приложения Expo.

Для Cursor и других агентов устанавливайте Expo Skills и сервер Expo MCP по отдельности. В разделе «AI-агенты и обзор Expo» описана настройка для каждого агента.
